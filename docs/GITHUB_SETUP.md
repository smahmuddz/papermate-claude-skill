## Social preview image
Upload a 1280x640 image (Settings > General > Social preview) showing the name "PaperMate" and the tagline "Try to kill your research idea before it costs you months."

## Other SEO tips
- Replace `YOUR-USERNAME` and `[Your Name]` in `README.md`, `LICENSE`, and `CITATION.cff`.
- Pin the repository on your GitHub profile.
- Create a release (v1.0.0) and attach `dist/papermate.skill`; release pages are indexed separately.
- Keep the first paragraph of the README keyword-rich but readable; it becomes the search snippet.
- Add a short demo GIF or screenshot of a real session once you have one.
- Share on relevant communities (Claude, NLP, grad-school forums) with a link to the release, not just the repo.
- Star-worthy signals: clear install steps, examples, license, citation file, and active issues/PRs.
